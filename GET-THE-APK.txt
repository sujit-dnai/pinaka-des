PINAKA 2.1.0: GPS FIX (28-Sep). Fixes "GPS is off" when GPS is on, so tracking no longer stops for the day.
1. Upload the "www" folder from this zip to github.com/sujit-dnai/pinaka-des (Add file → Upload files) → Commit.
2. Actions → "Android build" → wait for the green tick (~5 min).
3. Open the run → Artifacts → "pinaka-debug-apk" → unzip → app-debug.apk → send to the phone → install over the old one.
4. On the phone: Settings → Apps → Pinaka → Permissions → Location → "Allow all the time" + "Use precise location" on.
