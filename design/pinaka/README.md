# Pinaka · designs

Open any `.dc.html` file in a browser. Keep all the files in this folder together: the main pages load the component files next to them and `support.js`.

Start with these main pages:
- `Pinaka Full App.dc.html`: all 15 screen groups, with an index at the top
- `Case Sync.dc.html`: portal ↔ app sync, meetings ring, fines
- `Expenses.dc.html`, `Translator.dc.html`, `Tracking.dc.html`
- `Final Report.dc.html`, `Shared Case.dc.html`, `Team Chat Mentions.dc.html`

Developer hand-off: `docs/Handoff-Pinaka.md` and `docs/Handoff-CaseSync.md`. Rules: `docs/QUEUE.md`.

All data is sample. Design only; this folder is not app code.
