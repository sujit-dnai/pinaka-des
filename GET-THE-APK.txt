APP — Pinaka 2.1.2 (28-Sep). Upload to github.com/sujit-dnai/pinaka-des  (NOT skd-portal)
New in 2.1.2: the ringing screen shows the case — insured / petitioner, client, hospital, police station, address, phone, trigger.
Plus everything in 2.1.1 (start screen, Translator, uploads, GPS, no gallery, Leave, one phone).

1. Open the unzipped folder. Upload EVERYTHING inside it to pinaka-des (Add file → Upload files → drag the
   folders "www", "android", "ios" and the files package.json, package-lock.json, README.md) → Commit.
2. Actions → "Android build" → wait for the green tick (~3 min). Use the NEWEST run.
3. Open the run → Artifacts → "pinaka-debug-apk" → unzip → app-debug.apk → install over the old one.
4. In the app: Profile → the bottom line must say "Pinaka 2.1.2".
5. When the new app is on the phones: Portal → Pinaka App → Officers tab → "Oldest app allowed"
   → type 2.1.2 → Save. Older phones are then told to install the new app.
